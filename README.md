# 🌐 Portfolio Website — I Kadek Aldi Pranatha

Website portofolio dan biodata diri untuk **I Kadek Aldi Pranatha** (Mahasiswa S1 Sistem Informasi, Universitas Pendidikan Ganesha).

🔗 **Live Website:** [https://kadekaldipranatha-del.github.io/porto/](https://kadekaldipranatha-del.github.io/porto/)

---

## ✨ Fitur & Keunggulan
- 🖤 **Modern Full-Black Minimalist UI**: Desain elegan bernuansa *dark mode* dengan sentuhan *glassmorphism* dan tipografi modern (*Plus Jakarta Sans & JetBrains Mono*).
- ⚡ **100% Pure HTML5 & CSS3**: Dibangun sepenuhnya tanpa JavaScript untuk performa maksimal, ringan, dan cepat diakses di semua perangkat.
- 🔍 **Pure CSS Lightbox Modal**: Fitur zoom foto profil dan galeri foto interaktif menggunakan selektor murni CSS `:target`.
- 🎓 **Education Timeline**: Riwayat pendidikan terstruktur dan dinamis dari SD hingga Perguruan Tinggi.
- 📱 **Fully Responsive Layout**: Tampilan presisi dan proporsional di smartphone, tablet, maupun layar desktop.
- 🔗 **Direct Active Contacts**: Tautan langsung ke WhatsApp, Email (*mailto*), Instagram, LinkedIn, dan GitHub.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5** (Semantic Elements)
- **CSS3** (CSS Custom Properties / Variables, Grid, Flexbox, Animations & Pseudo-classes)
- **GitHub Pages** (Hosting & Deployment)

## 💻 Menjalankan Secara Lokal
Cukup buka file `index.html` langsung di browser Anda, atau jalankan server lokal:

```bash
# Menggunakan python http server
python -m http.server 8000
```
Lalu buka `http://localhost:8000` pada browser Anda.
