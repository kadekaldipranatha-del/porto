# 🌐 Portfolio Website — I Kadek Aldi Pranatha

Website portofolio dan biodata interaktif untuk **I Kadek Aldi Pranatha** (Mahasiswa S1 Sistem Informasi).

🔗 **Live Website:** [https://kadekaldipranatha-del.github.io/porto/](https://kadekaldipranatha-del.github.io/porto/)

---

## ✨ Fitur Utama
- 🎨 **Modern Dark UI Design**: Glassmorphism, smooth micro-interactions, dan typography estetik (*Plus Jakarta Sans & JetBrains Mono*).
- 🎵 **Floating Music Player**: Pemutar musik latar belakang dengan visual disc vinyl animasi, tombol navigasi lagu, kontrol minimalkan (floating bubble), serta playlist jingle & lagu favorit.
- 📱 **Fully Responsive**: Tampilan optimal di desktop, tablet, dan smartphone.
- 📬 **Interactive Contacts**: Salin email instan ke clipboard dengan toast notification dan link langsung ke WhatsApp & Instagram.
- 🚀 **Automated GitHub Pages Deployment**: Otomatis ter-deploy secara langsung melalui GitHub Actions.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5 & CSS3** (Vanilla CSS dengan CSS Custom Variables)
- **Vanilla JavaScript** (DOM API, Web Audio API)
- **GitHub Actions & GitHub Pages**

---

## 💻 Menjalankan Secara Lokal
Cukup buka file `index.html` langsung di browser Anda, atau gunakan Live Server:

```bash
# Menggunakan python http server
python -m http.server 8000
```
Lalu buka `http://localhost:8000` di browser.
